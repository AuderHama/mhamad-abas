# Mohammad Abbas — Biology Teacher Site

Static GitHub Pages site with a **design picker hub** and **10 homepage styles**.

## Preview locally

Open `index.html` in a browser, or from this folder:

```bash
npx --yes serve .
```

## Publish on GitHub Pages

1. Create a new GitHub repo (e.g. `mohammad-abbas`).
2. Upload everything in this folder (or `git push`).
3. Repo **Settings → Pages → Build and deployment**
4. Source: **Deploy from a branch**
5. Branch: `main` / folder: `/ (root)` → Save
6. Site URL will be like `https://USERNAME.github.io/REPO/`

## Pick a final design

1. Open the live hub (`index.html`).
2. Click through designs **01–10**.
3. Tell which number you want as the real homepage — we can promote that file to `index.html`.
